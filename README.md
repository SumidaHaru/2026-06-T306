# ゲーム名

「Unknown World」

# ゲーム概要

本作は、アクションとミステリー要素を組み合わせた2Dアクションゲームです。プレイヤーは謎に包まれた世界を探索しながら、敵との戦闘やステージ攻略を進めていきます。ターゲット層は20代から30代のプレイヤーで、アクションの爽快感と物語の謎解きを楽しめる作品を目指しています。

# 開発環境

* ゲームエンジン：Unity
* プログラミング言語：C++

# ゲームジャンル

* 2Dアクション
* ミステリー

# プレイヤー操作

プレイヤーキャラクターは、2Dアクションゲームの代表作であるマリオシリーズのような操作感を採用しています。

### 移動

* 左右キーで左右移動
* ジャンプボタンでジャンプ

### 攻撃

* 右クリックで攻撃
* 攻撃が敵に命中するとダメージを与える
* ダメージを受けた敵は点滅（チカチカ）し、被弾エフェクトが表示される

# プレイヤーの体力システム

プレイヤーは3つのライフ（体力）を持っています。

* 初期ライフ：3
* 敵の攻撃を受けるとライフが1減少
* ライフが0になるとゲームオーバー

# 敵キャラクター

### 通常行動

敵はステージ内を左右に巡回します。

### 壁への対応

敵が壁にぶつかった場合は、進行方向を反転して反対方向へ移動します。

### 穴への対応

敵が穴へ落ちそうになった場合は、その手前で方向転換し、反対方向へ移動します。

### プレイヤー発見時

敵は一定範囲内でプレイヤーを発見すると追跡モードへ移行します。

### 攻撃行動

追跡中にプレイヤーとの距離が近くなると攻撃を行い、プレイヤーのライフを減少させます。

# ゲームの特徴

* マリオ風のシンプルな2Dアクション操作
* ミステリー要素を含むストーリー
* ライフ制による緊張感のある戦闘
* 敵の巡回・追跡AI
* 被弾時の点滅エフェクトによる分かりやすい演出
* 20代〜30代を対象としたアクションアドベンチャー作品

# ゲームの流れ

1. プレイヤーがステージを探索する。
2. 敵を発見し、攻撃や回避を行う。
3. 敵からの攻撃を受けるとライフが減少する。
4. 謎を解きながらステージを進める。
5. ライフがなくなるとゲームオーバーとなる。
6. ステージの目的を達成するとクリアとなる。
